# 🚀 Proyectos de Prueba & Buscador de Empleo IA

¡Bienvenido a mi primer repositorio en GitHub! Este proyecto está diseñado para aprender a programar en Python mientras construyo herramientas reales y útiles.

## 📂 Estructura del Proyecto

- [`busqueda_empleo/`](busqueda_empleo/) — Módulo principal para gestionar mi búsqueda de trabajo asistida por Inteligencia Artificial:
  - [`cv/`](busqueda_empleo/cv/) — Carpeta para guardar mi Currículum Vitae (en texto/Markdown o PDF) y perfil profesional.
  - [`docs/`](busqueda_empleo/docs/) — Guías y plantillas de **Prompts de IA** para optimizar el CV, redactar cartas de presentación y preparar entrevistas.
  - [`notebooks/`](busqueda_empleo/notebooks/) — Jupyter Notebooks interactivos para buscar, filtrar y **recargar ofertas de empleo** en tiempo real.
  - [`ofertas/`](busqueda_empleo/ofertas/) — Historial de ofertas guardadas (en formato JSON/CSV) para hacer seguimiento de mis candidaturas.

## 🛠️ Cómo empezar

1. Abre la carpeta `C:\Users\marcm\.gemini\antigravity\scratch\Repo-de-prueba` como tu **Espacio de Trabajo (Workspace)** en Antigravity.
2. Sube o pega tu CV dentro de [`busqueda_empleo/cv/mi_cv.md`](busqueda_empleo/cv/mi_cv.md).
3. Explora los prompts en [`busqueda_empleo/docs/guia_prompts_empleo.md`](busqueda_empleo/docs/guia_prompts_empleo.md).
4. Abre el notebook [`busqueda_empleo/notebooks/buscador_ofertas.ipynb`](busqueda_empleo/notebooks/buscador_ofertas.ipynb) para recargar ofertas de trabajo en vivo y cruzarlas con las habilidades de tu CV.
